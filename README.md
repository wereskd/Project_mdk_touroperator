# Автоматизированная система «ТурОператор»

Проект выполнен в рамках дисциплины «Технология разработки программного обеспечения» (МДК 02.01).

## Описание
Десктопное приложение для автоматизации бизнес-процессов туроператорской компании. 
Реализовано на Python (PyQt6) с использованием локальной базы данных SQLite.

## Роли и пароли (для входа)
Пароль для всех пользователей: **123**
- `admin` — Администратор
- `manager` — Менеджер продаж
- `analyst` — Аналитик
- `purchasing` — Менеджер закупок
- `guide` — Гид-сопровождающий
- `accountant` — Главный бухгалтер
